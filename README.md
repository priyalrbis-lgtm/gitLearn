# GitLearn

## About This Repository

GitLearn is a practice repository that I created to learn and understand **Git and GitHub**.

The main purpose of this repository is to practice different Git commands, understand version control concepts, and learn how to work with remote repositories on GitHub.

I will use this repository to experiment with Git features and commands without affecting any real project.

## What I Am Learning

Through this repository, I am practicing:

- Git basics
- GitHub basics
- Creating and managing repositories
- Creating branches
- Switching between branches
- Making commits
- Writing meaningful commit messages
- Pushing changes to GitHub
- Pulling changes from GitHub
- Fetching remote changes
- Merging branches
- Resolving merge conflicts
- Working with remote repositories
- Using `.gitignore`
- Creating and managing tags
- Reverting and resetting changes
- Viewing commit history
- Understanding Git workflow
